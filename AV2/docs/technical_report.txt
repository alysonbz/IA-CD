Sobre o Dataset:

	A análise de personalidade do cliente é uma análise detalhada dos clientes ideais de uma empresa. Ajuda uma empresa a entender melhor seus clientes e facilita a modificação de produtos de acordo com as necessidades específicas, comportamentos e preocupações de diferentes tipos de clientes.

	A análise da personalidade do cliente ajuda uma empresa a modificar seu produto com base em seus clientes-alvo de diferentes tipos de segmentos de clientes. Por exemplo, em vez de gastar dinheiro para comercializar um novo produto para cada cliente no banco de dados da empresa, uma empresa pode analisar qual segmento de clientes é mais provável comprar o produto e, em seguida, comercializar o produto apenas nesse segmento específico.

ESTRATÉGIA PARA REDUÇÃO DE DIMENSIONALIDADE
Para a redução de dimensionalidade, será utilizada a Padronização (StandardScaler).
Justificativa: PCA é sensível à escala das variáveis. A padronização garante que todas as variáveis contribuam igualmente para a análise de componentes principais, pois transforma os dados para terem média 0
e desvio padrão 1. Isso é crucial quando as variáveis têm diferentes unidades de medida ou escalas, como é o caso deste dataset (renda, gastos, número de compras, etc.).
Normalização (MinMaxScaler) seria mais apropriada se a distribuição dos dados fosse muito assimétrica ou se o algoritmo subsequente fosse sensível a valores fora de um intervalo específico (e.g., 0-1), o que
não é o principal foco aqui para PCA.
Transformações específicas (e.g., logarítmicas) seriam consideradas se houvesse variáveis com distribuições muito enviesadas que precisassem ser normalizadas antes da padronização,
mas para a aplicação de PCA, a padronização é o passo mais crítico.

IDENTIFICAÇÃO DE ATRIBUTOS REDUNDANTES (APÓS PRÉ-PROCESSAMENTO)
Além das colunas Z_CostContact e Z_Revenue já removidas por terem variância zero, a matriz de correlação (correlation_matrix.png) será usada para identificar atributos com alta correlação (e.g., > 0.8 ou < -0.8).
Variáveis com alta correlação positiva ou negativa indicam redundância, pois carregam informações semelhantes. Por exemplo, se 'MntWines' e 'MntMeatProducts' fossem altamente correlacionadas, uma delas poderia
ser considerada redundante para a redução de dimensionalidade, embora ambas sejam mantidas para a interpretação semântica dos clusters.
Neste dataset, a análise visual da matriz de correlação não aponta para correlações extremamente altas (acima de 0.9) entre as variáveis numéricas restantes que justifiquem a remoção automática antes do PCA, que já
lida com a variância conjunta. No entanto, é importante notar que 'NumWebPurchases' e 'NumCatalogPurchases' podem ter alguma correlação com 'MntWines' e outros gastos, mas não a ponto de serem consideradas
totalmente redundantes para o PCA.
